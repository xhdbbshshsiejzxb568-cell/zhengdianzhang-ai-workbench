# 文稿：东西放哪里

> 模板用法：拷到自己电脑的「文稿」首页，命名为 `文稿分类说明.md`。把〈〉里的内容换成自己的，删掉用不上的行。

**一句话：内容放「1_内容系统」，正在做的放「2_剪辑工作」，AI 的东西从「4_AI工具」进，私人的放「5_个人资料」。不知道放哪，就先放「3_待归类」。**

文件夹按用得多少排序，序号越小越常用。

| 文件夹 | 放什么 | 对应备忘录 |
| --- | --- | --- |
| 1_内容系统 | 知识库、素材、账号作品、归档 | 〈你的主题分类〉 / 归档 |
| 2_剪辑工作 | 正在制作的工程、候选、缓存 | — |
| 3_待归类 | 刚下载、还不知道放哪的（唯一收件箱） | 收件箱 |
| 4_AI工具 | 所有 AI 的总入口：每个 AI 一个文件夹 | — |
| 5_个人资料 | 证照、家庭、学习资料 | 个人 |
| 6_软件资料 | 安装包、迁移包 | — |

## 内容系统，按一条内容的先后顺序排

1_收件箱 → 2_灵感 → 3_知识库 → 4_素材库 → 5_账号作品 → 〈6_你的特色板块〉 → 7_方法工具 → 8_归档

## 视频只有一个去处

| 视频是什么 | 放哪里 |
| --- | --- |
| 原片和素材 | 1_内容系统/4_素材库 |
| 正在剪的 | 2_剪辑工作/AI名字/账号/主题 |
| 成片 | 1_内容系统/5_账号作品/账号/正式作品/主题 |
| 不再用的 | 1_内容系统/8_归档 |

## 下载和新增文件放哪（所有 AI 都按这张表）

| 下载的是什么 | 统一放哪 |
| --- | --- |
| 软件安装包 | 6_软件资料/安装包/软件名 |
| 对标视频、参考作品 | 1_内容系统/4_素材库/对标与参考 |
| 自己的原片、录屏、声音 | 1_内容系统/4_素材库 对应子文件夹 |
| 行业资料、报告、文章 | 1_内容系统/3_知识库 对应主题 |
| 课程、学习资料原件 | 5_个人资料/学习资料 |
| 为某个任务抓的数据 | 4_AI工具/AI名字/任务名 |
| AI 自己要用的模型、依赖 | 各 AI 自己的设置文件夹，不进文稿 |
| 拿不准的 | 3_待归类 |

四条硬规矩：
1. 下载前先按表定好位置，不放「下载」文件夹、桌面、临时文件夹。
2. 下载完要汇报：下了什么、放在哪。
3. 先查后下：已经有的不重复下载。
4. 文件名统一用 `日期_来源_内容`。

## 软件和工具（装新软件三件事）

1. 安装包放进 `6_软件资料/安装包/软件名`。
2. 在软件设置里把下载、导出、录屏位置改到对应分类。
3. 在 `6_软件资料/软件清单.md` 补一行；AI 工具还要到 `4_AI工具` 加入口。

## 绝对不要动

- AI 的默认工作台（比如文稿里的 `Codex`）：必须是原位置的真文件夹，在访达里隐藏可以
- 所有隐藏的旧名字链接
- 〈剪辑软件草稿文件夹、外接硬盘素材库等〉

## 给所有 AI 的规则

所有 AI 的分工和配合方式，见 `4_AI工具/AI协作手册.md`。

- 过程放「4_AI工具/AI名字/任务名」，成品回「1_内容系统」，不按"哪个 AI 做的"来分。
- 不知道放哪：放进「3_待归类」，不要先复制到好几个分类里。
- 不在文稿首页新建文件夹；有新类别，就在对应文件夹下面建子文件夹。
- 挪动或改名任何文件夹之前，先全局搜索哪里引用了它；改完要验证工具还能用。
