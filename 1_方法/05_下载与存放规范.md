# 05 下载与存放规范

## 解决什么问题

让不同的 AI 去下载东西，结果有的放在「下载」，有的放桌面，有的留在 AI 自己的工作台里，时间一长就找不到了。

## 怎么做

**1. 一张"下载放哪表"，所有 AI 都按它来放**（正本在「文稿分类说明」里）：

| 下载的是什么 | 统一放哪 |
| --- | --- |
| 软件安装包 | 6_软件资料/安装包/软件名 |
| 对标视频、参考作品 | 4_素材库/对标与参考 |
| 自己的原片、录屏、声音、数字人素材 | 4_素材库 对应的子文件夹 |
| 楼盘资料（户型图、规划、宣传册） | 3_知识库/房产/楼盘数据库/楼盘名 |
| 政策、报告、行业文章 | 3_知识库 对应主题 |
| 课程、学习资料原件 | 5_个人资料/学习资料 |
| 为某个任务抓的数据（评论、榜单、表格） | 那个任务的文件夹 |
| AI 自己干活要用的模型、依赖 | 各 AI 自己的抽屉，不放进文稿 |
| 拿不准的 | 3_待归类 对应的子文件夹 |

**2. 四条硬规矩：**
1. **下载前先按表定好位置**：不放「下载」文件夹、桌面、临时文件夹。
2. **下载完要汇报**：下了什么、放在哪。
3. **先查后下**：电脑里已经有的，不重复下载。
4. **文件名统一用 `日期_来源_内容`**，比如 `2026-10-15_抖音_某楼盘测评.mp4`。原文件名有用的话，接在后面保留。

**3. 手机拍的原片：移动，不要复制。**
手机隔空投送的视频会先落到「下载」。AI 接手剪辑时，把原片**移动**到 `4_素材库/房产口播原片/主题`，剪辑工程只记录原片在哪，不再放第二份。否则「下载」里一份、工程里一份，一条片子就白占几百兆。

**4. 手动下载和录屏的习惯：**
- 刚下载或刚录好的文件，**先等几分钟，确认写完了再挪**，免得挪了一个写了一半的文件。
- 网上下载的视频只能放进「对标与参考」，不能当成自己的原片。
- 判断放哪时，先看文件名、格式和来源；证据不够，再打开看内容；还是看不出来，就放进待归类，并写清楚还缺什么信息，不要猜。

**5. 每周快速检查一次：** 看看「下载」、桌面、待归类里有没有新东西。没有就结束，有就按表归位。

## 怎么算做好

- 「下载」文件夹和桌面上没有该长期保存的文件
- 待归类里只剩真正缺信息、没法判断的
- 随便哪个 AI 下载的东西，都在表里写的位置

## 踩过的坑

- 下载文件夹里可能混着**登录凭证**一类的敏感文件（比如账号的登录令牌导出文件）。看到这类文件不要挪进文稿、不要发给任何人，告诉本人，由本人处理。
- 实际用了两天就发现：手机原片被复制进剪辑工程后，「下载」里还留着一份一模一样的（131M）。原因是素材库里当时没有"口播原片"这个位置，所以先把位置定好，规矩才能落地。
- 和已有文件一模一样的重复下载，先核对确实完全相同，再移到废纸篓。
