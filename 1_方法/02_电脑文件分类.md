# 02 电脑文件分类

## 解决什么问题

文件到处放；同一条视频有原片、候选版、过程检查、缓存好几个版本，找不到正式版；文件夹名字太长、顺序乱。

## 怎么做

**1. 文稿首页只留 6 个带序号的文件夹，按用得多少排序。**

| 文件夹 | 放什么 | 对应备忘录 |
| --- | --- | --- |
| 1_内容系统 | 知识库、素材、账号作品、直播切片、归档 | 房产 / AI / 资料库 / 归档 |
| 2_剪辑工作 | 正在制作的视频工程、候选、缓存 | — |
| 3_待归类 | 刚下载、还不知道放哪的（唯一收件箱） | 收件箱 |
| 4_AI工具 | 所有 AI 的总入口 | — |
| 5_个人资料 | 证照、家庭、学习资料 | 个人 |
| 6_软件资料 | 安装包、迁移包、网络配置 | — |

再放一份「文稿分类说明.md」在首页，写清楚上面这张表，人和 AI 都看它。

**2. 内容系统按"一条内容的先后顺序"排。**

1_收件箱 → 2_灵感 → 3_知识库 → 4_素材库 → 5_账号作品 → 6_直播切片 → 7_方法工具 → 8_归档

**3. 视频只有一个去处。**

| 视频是什么 | 放哪里 |
| --- | --- |
| 原片和素材（实拍、口播原片、对标、数字人、录屏） | 4_素材库 |
| 正在剪的工程 | 2_剪辑工作/AI名字/账号/主题 |
| 成片（已发布的作品） | 5_账号作品/账号/正式作品/主题 |
| 直播回放和切片 | 6_直播切片 |
| 不再用的旧视频 | 8_归档 |

**4. 一条视频从头到尾：**
1. 文案在备忘录里写好。
2. 在剪辑工作里制作。
3. 做完以后，成片和最终文案放进账号作品。
4. 发布后，候选版、过程检查、缓存这些中间版本可以删，只留成片和原片。
5. 讲过的话（直播、口播文稿）同步进知识库的「直播与口播语料」，以后写稿能查到自己说过什么。

**5. 命名规则。**
- 序号只用来排顺序。
- 不用相机流水号、随机编码、无意义的日期串给文件夹起名。
- 版本号、分辨率、户型编号这类有意义的数字可以保留。
- 同一类东西只用一个固定名字。比如候选和质检都叫「候选与质检」，不要同时出现「测试成片」「质量记录」这种同义的文件夹。

## 改名不断路：隐藏链接

文件夹换了新名字以后，很多旧脚本、AI 技能、剪映草稿里还写着旧路径。做法是在旧位置留一个指向新位置的链接，再把这个链接在访达里隐藏：

```bash
ln -s "新名字" "旧名字"
chflags -h hidden "旧名字"
```

这样访达里只看到新名字，旧路径照样能用。这些隐藏链接不是重复资料，**不要删**。想看的话，在访达里按 ⌘⇧.（Command + Shift + 句号）就会显示出来。

## 怎么算做好

- 文稿首页只有 1 到 6 号文件夹和一份说明
- 每条正式视频只有一个正式版，旁边配同名的最终文案
- 随便问一个东西放在哪，都能按表直接说出位置
- 改名以后，AI 技能和剪辑工具都能正常运行

## 踩过的坑

- 旧资料并进知识库时，**先去重再合并**：只留新档案里没有的内容，重复的删掉，并注明是从哪里合并过来的。
- 有些名字看起来像旧东西的文件夹，其实是工具的运行目录（比如放 FFmpeg 的「历史任务工作区」）。动之前先查清楚有没有被引用，见 [06 安全整理原则](06_安全整理原则.md)。
